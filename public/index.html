Projects

  • Football Player Undervaluation Model with RAG Scouting Assistant

    Built an end-to-end football analytics and machine learning system that identifies potentially undervalued players moving between European leagues. Uses Python, PyTorch, scikit-learn and PostgreSQL to predict player development, alongside a retrieval-augmented generation (RAG) assistant that allows scouts to query player statistics and scouting reports with cited sources. Achieved 90% accuracy on a held-out assistant evaluation.

    GitHub Repository

  • Premier League Match Prediction Pipeline

    Developed an automated machine learning pipeline that collects and processes football data, engineers team performance features using PySpark, and predicts upcoming Premier League match outcomes. Uses historical seasons for model training and evaluation, with GitHub Actions automating daily updates, scheduled predictions and weekly model retraining. Publishes predictions through a live dashboard.

    GitHub Repository

  • Toronto Housing and Shelter Forecasting Pipeline

    Built an end-to-end data engineering and forecasting project combining public Toronto shelter occupancy data with Bank of Canada interest rate data. Developed a 433,000-row data warehouse using dbt and DuckDB, implemented automated data quality tests, and applied statistical modelling and time-series forecasting to investigate relationships between interest rates and shelter demand.

    GitHub Repository
